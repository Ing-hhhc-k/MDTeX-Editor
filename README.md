# MDTeX Editor 0.3

面向本机阅读与写作的 Markdown 编辑器。React + Tiptap / ProseMirror + KaTeX + Electron，黑白灰界面，无需账号或云端服务。

版本变更见 [CHANGELOG.md](CHANGELOG.md)，LaTeX 阅读与编辑的后续设想见 [ROADMAP.md](ROADMAP.md)。当前尚未实现 LaTeX 文档编辑与编译。

## 0.3 新功能

- 点击工具栏“表格”，在下方浮动网格中移动选择尺寸，再点击对应格子立即插入。
- 公式面板新增“括号 / 希腊字母 / 常用字符”，可在源码光标处插入独立符号。
- 点击“图片”选择本地文件，也可在编辑或源码区域直接粘贴剪贴板图片。支持 PNG/JPEG/GIF/WebP/BMP，单张上限 8 MB，使用 data URL 嵌入 Markdown，无需维护图片附件路径。大图会增加文档体积及草稿存储占用，请及时保存文件。
- 侧栏“打开文件夹”选择工作目录，支持递归展开目录、新建、读取、编辑、重命名和删除 `.md` / `.markdown`。其他文件仅展示，不读取。删除会移到系统回收站；已打开文档的未保存内容保留为脱离原路径的草稿。新建/重命名不覆盖同名文件。
- 文件夹树可手动刷新。已有文件通过 Ctrl+S 保存回原位置；新草稿仍可另存为指定位置。文件夹选择在当前会话有效，重启后重新选择。

## 直接使用

双击 `release/MDTeX/MDTeX.exe`。这是 Windows x64 免安装目录版，移动时请保留整个 MDTeX 文件夹，不能只复制 exe。

## 已实现

- **编辑 / 阅读 / 源码 / 分屏**：渲染结果可编辑，阅读模式只读；分屏两侧均可修改。支持常用 Markdown、GFM 表格、任务列表、链接、图片和代码块。
- **快捷插入**：在空段落输入 `/`，或使用工具栏。表格支持网格选择尺寸、边缘加号增加末尾行列、右键在当前单元格附近增删行列、拖动列宽、Tab 切换单元格。
- **公式面板**：常用、微积分、线性代数、概率统计、符号五组模板；点击模板得到 LaTeX 源码，可修改并实时预览。支持 `$…$` 行内公式、`$$` 独立公式，独立公式居中。双击公式重新编辑。源码模式也可直接插入模板。
- **标题编号**：工具栏“编号”菜单提供全文自动编号、移除全文编号、仅编号当前标题、移除当前标题编号。全文模式会在新增、删除、调整层级时自动重排。单标题操作先将光标放入编辑视图中的标题，只修改该标题，按全文结构计算层级序号（其他未编号标题也参与计数），保留标题内加粗等格式。为保证其他标题不被改动，单标题操作会暂停全文自动重排；可随时再次选择全文自动编号。编号以普通文本保存，其他阅读器也可见。
- **多语言代码块**：代码块左上角选择语言并显示语法高亮，支持 Python、JavaScript、TypeScript、Java、C/C++、C#、Go、Rust、SQL、Shell、PowerShell、JSON、HTML/XML、CSS、YAML、Markdown、R、MATLAB、LaTeX 和纯文本。支持源文件中的 `js` / `py` 等常用别名；未知语言标签也会保留。切换语言不改变代码内容，语言标记保存在 Markdown 代码围栏中。每段代码仍可独立折叠，阅读模式允许折叠但禁止修改语言。
- **页面大小**：默认 110% 缩放、更宽的舒适页宽；右下角可在 70%–180% 间调节，点击百分比恢复 100%。紧凑、舒适、铺满窗口三种宽度可选。支持 Ctrl+加号/减号、Ctrl+0、Ctrl+鼠标滚轮；源码字体同步调整，显示设置自动记忆，不改变文件内容。
- **文件与草稿**：原生打开、保存、另存为；UTF-8 Markdown；写入完成后原子替换文件。本机草稿自动保存，多份草稿可切换。浏览器版保存为下载文件。
- 文档大纲、撤销重做、专注模式、快捷键面板。

## 开发

建议使用 Node.js 22 LTS 或更新版本。当前机器的 Node.js 18 也已完成构建与测试，但部分上游库声明要求 Node.js 20 以上。

```powershell
npm install --registry=https://registry.npmjs.org
npm run desktop        # 构建并启动 Electron
npm run dev            # 浏览器开发版，打开控制台显示的本机地址
npm test               # 编号单元测试
npm run test:desktop   # Electron 实际交互测试
npm run test:improvements # 单标题编号、代码语言、高亮、缩放与设置恢复
npm run dist           # 生成 release/MDTeX 目录版
```

首次安装需要联网下载依赖和 Electron。如果 Electron 下载无法连接，可在当前 PowerShell 会话设置镜像再安装，不需要改全局配置：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm install --registry=https://registry.npmjs.org
```

打包仅复制已有 Electron 运行时、构建产物和桌面入口，无需额外下载打包工具。Windows 版本暂未做代码签名。

## 使用边界

当前版本尚未集成飞书或 WPS 云同步。数学渲染使用 KaTeX，支持其 LaTeX 子集，不包含完整 TeX 编译器或所有 MathType 功能。图片支持 Markdown URL；相对本地图片路径的解析、图片资源管理尚未实现。

所见即所得编辑后会生成规范化的 Markdown，因此空行、列表符号、表格对齐等源码排版可能变化。脚注、Mermaid、自定义 HTML / 非标准 Markdown 扩展不保证往返保真；这类文档建议先另存副本，使用源码模式修改和保存。

源代码中的标题编号如 `1.2 标题` 会被识别为编号前缀，移除编号时会一并去掉；标题若本来以“数字 + 空格”开头，也会被视作编号。自动编号模式下，在源码中修改标题后，切回编辑/阅读或保存时将同步最新编号。

草稿保存在 Electron 用户数据目录的 localStorage 中，约受浏览器 5–10 MB 配额限制；超出配额会提示保存文件。草稿不是备份，请通过 Ctrl+S 保存重要文件。程序不会上传文档；文档若包含外部图片，显示图片时仍会请求对应 URL。

## 验证

编号测试覆盖多级、同级、跳级、移除、重排、幂等及指定标题作用域。Electron 交互测试覆盖启动渲染、只读、公式往返编辑、表格右键/边缘加号、代码折叠、编号快捷键、分屏连续编辑、文件读写和草稿恢复。新增交互测试覆盖全文/单标题切换、格式保留、代码语言切换及高亮、围栏语言保存、缩放快捷键、页宽和显示设置恢复。
