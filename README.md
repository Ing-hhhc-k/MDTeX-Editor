# MDTeX Editor 0.5.5

本地 Markdown 阅读与编辑器，黑白灰界面。支持所见即所得、只读阅读、源码及双向分屏，包含数学公式、表格、多语言代码高亮、图片、文件树和多文档标签页。无需账号，不上传文档。版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 运行

**当前版本 0.5.5。** Windows ZIP 发布在下方 GitHub 下载页。

**普通用户：[下载 Windows 免安装版](https://github.com/Ing-hhhc-k/MDTeX-Editor/releases/latest)。** 在发布页的 Assets 中下载对应版本的 Windows ZIP，完整解压后双击最外层 `MDTeX.exe`。

**启动入口就在项目最外层：双击 `MDTeX.exe`。** 源码首次使用请先运行下方的 `npm install` 和 `npm run dist`，生成运行文件。

本地构建的 Windows 免安装包位于项目最外层：**`MDTeX-Editor-0.5.5-win-x64.zip`**。解压后的最外层直接有 `MDTeX.exe`，无需再进入子文件夹；运行依赖放在 `_internal` 中。不能只下载或复制单独的启动 exe。

## 手动保存与本地文档

0.5.5 起关闭正文自动保存。编辑内容先留在当前窗口，按 **Ctrl+S** 才写入文件；关闭有修改的标签或退出软件时，可选择保存、不保存或取消。

没有指定保存路径的新文档，Ctrl+S 默认保存到 exe 同级的 `MDTeX-data/documents/<文档 ID>/<文档名>.md`，引用的本地图片存入该文档目录的 `picture`。按 **Ctrl+Shift+S** 可另存为到其他位置，生成同名文档文件夹。

侧栏“本地文档”列出尚未保存的新文档和 data 中已保存的文档。点击删除需确认；data 中的文档及图片移入回收站，若仍有未保存修改则保留在标签中。外部打开的 .md 不复制到 data。

文件夹中仅 .md 可打开、新建、重命名或删除，.markdown、.txt 等其他后缀仅展示，不可操作。

## 主题与版本更新

顶部可选择浅色、暗色或跟随系统，主题会自动记忆，覆盖侧栏、编辑/阅读/源码、表格、公式和弹窗。暗色主题不反转图片颜色。

程序启动后检查 GitHub 最新正式版，可在“检查更新”中关闭。完整解压的免安装版可点击 **更新并重启**：先询问并保存未保存的修改，下载并验证 GitHub 发布包的 SHA-256，在原目录替换程序，随后重启。新版成功启动后清理旧程序文件，`MDTeX-data` 与原路径文档保留；替换或启动失败时尝试恢复旧版。下载失败时不退出、不替换程序。更新过程中请勿移动程序目录或断电。源码开发运行与项目根目录的构建快捷入口仅支持手动下载，自动替换需要从 `release/MDTeX/MDTeX.exe` 或解压后的正式版启动。

网络受限、目录无写入权限或发布包未提供校验信息时，可使用“下载 ZIP”或 README 顶部入口手动更新。0.4.x 没有自动安装能力，首次升级到 0.5.0 仍需下载完整 ZIP。

## 本地数据位置与迁移

0.4.3 正式 Windows 版的旧数据位置为 `%APPDATA%\MDTeX`（本机为 `C:\Users\jhc\AppData\Roaming\MDTeX`）；开发版通常为 `%APPDATA%\mdtex-editor`。旧版 `drafts` 只包含暂存正文和图片，草稿列表、标签和部分设置另存在浏览器本地存储中，单独复制 `drafts` 不能完整恢复。

从 0.5.0 开始，数据放在**最外层启动程序 `MDTeX.exe` 同级**的 `MDTeX-data`，启动时创建，不随安装包分发。可在“检查更新 → 打开数据文件夹”查看实际位置。

```text
MDTeX.exe
_internal/                程序运行文件
MDTeX-data/               更新时保留、迁移时整体复制
├── session.json          文档路径与标签索引，不保存正文缓存
├── preferences.json      主题、显示及更新设置
├── files.json            已打开文件和文件夹记录
├── documents/
│   └── 文档ID/
│       ├── 文档名.md      Ctrl+S 手动保存
│       └── picture/
├── migration-backups/    首次升级前的旧会话备份（如有）
├── drafts/               旧版暂存目录（保留，不再写入）
└── …                     本地应用数据、缓存及更新记录
```

首次使用新版前请关闭旧版。若新版还没有数据目录，会复制旧用户目录的数据并转换草稿图片路径，**保留旧目录作为备份**；已有 `MDTeX-data` 时以该目录为准，不再覆盖。请在迁移后核对草稿。程序目录必须可写，建议解压在个人目录中。

手动升级或换目录时：关闭两个版本，备份后将旧版的**整个 `MDTeX-data` 文件夹**复制到新版 exe 同级。如果新版已经生成数据目录，应先备份并移走新版目录，再复制旧版，避免混合不同版本的数据。下次启动会修正暂存图片路径。外部已保存的 Markdown 和图片保留原路径，移动到另一台电脑时需另行复制或使用“打包 ZIP”。自动更新无需手动复制数据。

## 三种文件流程

### 1. 新建文档，手动保存

点击左侧 **+** 创建新文档。编辑正文及插入的图片先保留在当前窗口，不创建草稿目录，也不把正文自动写入会话文件。按 **Ctrl+S** 保存到 `MDTeX-data/documents/<文档 ID>`；后续按 Ctrl+S 更新同一文件。

按 **Ctrl+Shift+S** 选择其他位置，例如 `D:/笔记/研究笔记.md`，实际保存结构为：

```text
D:/笔记/研究笔记/
├── 研究笔记.md
└── picture/
    └── 图片内容哈希.png
```

本地图片复制到 `picture` 并使用相对引用，源图片保留；网络图片保持网址不下载。另存为保留原 data 文档，左侧仍可打开原副本。取消、图片缺失或写入失败时，当前编辑内容保持在窗口中。

首次升级到 0.5.5 时，旧会话中尚未保存的正文会一次性迁移到 `documents`；外部文件的未保存编辑生成独立的“恢复副本”，不覆盖外部原文件。旧会话另备份到 `migration-backups`，原 `drafts` 保留。后续启动、切换标签及重新打开文件均读取实际磁盘内容。

### 2. 打开文件夹，管理其中的文档

点击顶部 **打开文件夹**，左侧出现独立的 **文件树** 栏。支持展开子目录，在当前目录或子目录新建 `.md`，读取、编辑、重命名和删除文档；非 Markdown 文件仅展示，不读取。

- 选择文档，在顶部标签页切换。
- Ctrl+S 保存回原文档，本地图片放在文档所在目录的 `picture` 中。
- 删除会先显示确认框，再移入系统回收站；当前编辑内容保留在标签页中，可另存为，不新增草稿目录。
- 不覆盖同名的新建/重命名目标；可手动刷新文件树。

可以连续打开不同文件夹。每个标签记录各自的文件夹，点击标签会切换对应文件树。同名文档在标签中显示所属文件夹，悬停可查看完整路径。关闭标签不会删除磁盘文件；有未保存修改时会先询问。

### 3. 直接打开一个本地 Markdown

点击 **打开md文档** 或 Ctrl+O，选择 `.md`。单个本地文档不显示文件树栏。插入或粘贴的图片先保留在编辑内容中，不在 data 中建立文档目录；保存时写入文档旁的 `picture` 或选择的同名文件夹。文档索引只记住路径和标签，下次打开读取磁盘最新内容，未手动保存的修改不作为会话恢复。

如果文档有本地图片，Ctrl+S 会说明并提供：

- **原位置保存**：Markdown 保持原位置，图片复制到同级 `picture`，使用相对路径。
- **整理为文件夹**：复制当前文档和图片到同名文件夹，图片放进 `picture`，原文档和原图片都保留。之后按文件夹文档处理。
- **取消**：不写入，保留暂存内容。

没有本地图片时直接保存回原位置。没有本地未保存修改时，检测到外部改动会刷新当前文档；有本地修改时，显示冲突提示，可载入磁盘版本（需确认）、保留当前编辑或另存为副本。保存覆盖外部改动前会再次确认。另存为使用同名文档文件夹的结构。

## 图片与 ZIP

点击工具栏 **图片** 选择本地图片，或在编辑/源码区域 Ctrl+V 粘贴剪贴板图片。支持 PNG、JPEG、GIF、WebP、BMP，单次插入上限 8 MB，已有引用的单张图片整理上限 20 MB，单次整理总量上限 200 MB。

程序整理标准 Markdown 图片语法、图片引用定义及 HTML `img` 图片，忽略代码块和注释中的示例。支持相对路径、`file:` 本地地址、旧版 `data:image`；本地图片缺失时会报错，保留原文档和暂存。图片按内容哈希命名，避免重名覆盖，重复内容只保存一份。

点击 **打包 ZIP**，选择压缩包路径。ZIP 中包含同名顶层文件夹、**当前编辑内容**的 Markdown 和引用的本地图片目录 `picture`。无需先保存 Markdown；打包不修改原文件，也不清理临时目录。网络图片仅保留链接，离线时可能无法显示。未引用的附件和其他文档不会打包。

## 编辑功能

- 编辑 / 阅读 / 源码 / 分屏；编辑与源码切换时定位到当前光标或选区；文档大纲随滚动高亮当前章节；点击远处章节时侧栏直接保持所选章节，正文仍平滑跳转；手动保存、专注模式。
- 表格浮动网格点击插入，默认无标题行，可勾选首行设为标题行或右键切换；右键可设置 / 取消首列标题，标题行与标题列可同时存在，交叉单元格保持原样式；边缘 + 增行增列；右键增删、选中整表；列宽拖动。空表格内按 Backspace / Delete 可删除整表；有内容的表格在首格开头按 Backspace、末格末尾按 Delete 或相邻正文边界按对应键，先选中整表，再按一次删除，支持撤销。无标题行的表格以 Markdown 支持的 HTML 表格保存，切换视图、重开和打包保留设置与图片。
- 段落靠左、居中、靠右：作用于当前段落或所选的多个段落，也支持标题、表格内文字和独立公式；文字段落默认靠左，独立公式默认居中。居中和靠右通过 Markdown 支持的 HTML 标记保存，切换视图及重开后保留。
- 公式弹窗顶部提供醒目的“行内公式 / 独立公式”选择及对应预览；正文中默认插入行内公式，空白段落默认插入独立公式，也可双击已有公式切换类型。行内公式跟随正文对齐，不改变前后文字排版。
- 选中正文文字后点工具栏“公式”或按 Ctrl+Shift+M，直接将选中内容按 LaTeX 转换；段落中的一部分转换为行内公式，完整段落或多段内容转换为独立公式，默认居中。支持撤销，双击公式继续编辑；未选中文字时仍打开公式编辑窗口。
- 文字高亮：工具栏可选淡红、淡黄、淡绿、淡橙、淡灰及无色，保持文字可读。默认黄色使用 `==文字==`，例如 `==重点==`；其他颜色使用 Markdown 支持的 `<mark>` HTML 标记保存，源码切换和重新打开后保留颜色。无色移除选区高亮，加粗等文字格式保留。代码中的 `==` 不作为高亮解析。
- 数学公式模板、独立括号、希腊字母与常用字符；LaTeX 源码实时预览；支持直接输入、粘贴或在源码中使用 `$$…$$` 行间公式（同一行包裹或多行），独立公式默认居中，可用段落对齐工具调整并保留靠左/靠右设置；双击编辑，取消后保留原光标与滚动位置。模板优先插入公式输入框中定位的光标处或替换选中文字，未定位光标时更新整式；切换分类保留位置。
- 工具栏 **自动编号** 统一处理正文与标题：光标在正文时使用有序列表连续编号；在标题时只统计参与编号的标题，按实际父子关系连续编号。未编号的标题不占序号；在前面加入、取消、删除或移动已编号标题，后续已编号标题会重排。不编号的上级不出现在前缀中，例如二级标题先为 `1、2`，上级加入编号后变为 `1.1、1.2`。再次点击取消当前编号；全文编号仍有独立入口。
- 正文有序列表使用 `1. `、`2. ` 等编号，连续段落顺排；空段落或其他内容分隔后重新从 `1. ` 开始，空段落不参与编号。按两次 Enter 退出列表后保留分隔；保存、重开或切换源码也保留分组。
- 多语言代码块与语法高亮，左上角切换语言，右上角折叠和一键复制。左侧行号按实际换行计数（包含空行），长行自动折行，续行不编号，后续行号与实际换行位置对齐；表格内代码块也按单元格宽度自动折行，调整列宽、页宽或缩放后重新对齐；编辑、阅读及折叠状态均可复制代码正文，复制内容不含行号或 Markdown 围栏。
- 70%–180% 缩放、三种页宽，记忆显示设置。

首次安装 Electron 如遇下载问题，可在当前 PowerShell 设置镜像后重试：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm install --registry=https://registry.npmjs.org
```

构建使用 Vite 生成界面、esbuild 打包 Electron 主进程和文件处理依赖。免安装程序暂未做代码签名。

## 当前边界

文档路径和标签索引保存在本机，正文只在手动保存时写入。异常退出会丢失尚未保存的修改，请及时按 Ctrl+S；本地数据不能替代备份。

所见即所得编辑会规范化 Markdown 的空行、列表和表格等排版。脚注、Mermaid、自定义 HTML 等非标准扩展不保证往返保真。图片整理不处理 SVG，也不下载网络资源。

数学公式使用 KaTeX 支持的语法子集。浏览器开发版只提供基本编辑和 Markdown 下载；本机文件管理、暂存、图片整理与 ZIP 使用 Electron 桌面接口。当前不提供云同步。
