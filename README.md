# MDTeX Editor 0.4.2

本地 Markdown 阅读与编辑器，黑白灰界面。支持所见即所得、只读阅读、源码及双向分屏，包含数学公式、表格、多语言代码高亮、图片、文件树和多文档标签页。无需账号，不上传文档。版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 运行

**普通用户：[下载 Windows 免安装版](https://github.com/Ing-hhhc-k/MDTeX-Editor/releases/latest)。** 在发布页的 Assets 中下载 `MDTeX-Editor-0.4.2-win-x64.zip`，完整解压后双击最外层 `MDTeX.exe`。

**启动入口就在项目最外层：双击 `MDTeX.exe`。** 源码首次使用请先运行下方的 `npm install` 和 `npm run dist`，生成运行文件。

本地构建后，供其他人使用的 Windows 免安装压缩包也会放在项目最外层：**`MDTeX-Editor-0.4.2-win-x64.zip`**。解压后的最外层直接有 `MDTeX.exe`，无需再进入子文件夹；运行依赖放在 `_internal` 中。不能只下载或复制单独的启动 exe。

## 主题与版本更新

顶部可选择浅色、暗色或跟随系统，主题会自动记忆，覆盖侧栏、编辑/阅读/源码、表格、公式和弹窗。暗色主题不反转图片颜色。

程序启动后会检查 GitHub 最新正式版（可在“检查更新”中关闭），发现新版时顶部显示提示。点击“检查更新 → 下载新版 ZIP”，保存文档后完整解压新版，退出旧版并运行新文件夹最外层 MDTeX.exe。文档、草稿与主题设置保存在原路径或用户数据目录，不随程序文件夹替换。确认新版本正常后再删除旧程序文件夹。

暂不在程序内自动覆盖运行中的文件。网络受限时仍可使用 README 顶部的固定 Releases 下载入口；只有公开发布的 Windows ZIP 上传完成后才提示可下载。

## 三种文件流程

### 1. 新建草稿，再保存到本地

点击左侧 **+** 创建新文档。文字与插入的图片暂存于应用用户数据目录的 `drafts/<文档 ID>`；默认 Windows 位置为 `%APPDATA%/mdtex-editor/drafts`。各文档使用独立目录，不会混用图片。

按 Ctrl+S，选择保存位置并输入文档文件名。程序创建同名文件夹，例如选择 `D:/笔记/研究笔记.md`，实际保存结构为：

```text
D:/笔记/研究笔记/
├── 研究笔记.md
└── picture/
    └── 图片内容哈希.png
```

本地图片，包括插入、粘贴、其他本机路径引用和旧版内嵌图片，会复制到 `picture`，Markdown 改为相对引用。源图片保留，网络图片保持网址不下载。没有本地图片时可以不生成空的 `picture` 目录。

保存成功后清理该文档的临时目录，并自动显示生成文件夹的文件树。取消、目标冲突未确认、图片缺失或写入失败时不清理暂存内容。目标文件已经存在时会确认是否覆盖。

### 2. 打开文件夹，管理其中的文档

点击顶部 **打开文件夹**，左侧出现独立的 **文件树** 栏。支持展开子目录，在当前目录或子目录新建 `.md` / `.markdown`，读取、编辑、重命名和删除文档；非 Markdown 文件仅展示，不读取。

- 选择文档，在顶部标签页切换。
- Ctrl+S 保存回原文档，本地图片放在文档所在目录的 `picture` 中。
- 删除会先显示确认框，再移入系统回收站；已打开文档未保存的内容保留为草稿。
- 不覆盖同名的新建/重命名目标；可手动刷新文件树。

可以连续打开不同文件夹。每个标签记录各自的文件夹，点击标签会切换对应文件树。同名文档在标签中显示所属文件夹，悬停可查看完整路径。关闭标签不会删除文件或草稿。

### 3. 直接打开一个本地 Markdown

点击 **打开** 或 Ctrl+O，选择 `.md` / `.markdown`。单个本地文档不显示文件树栏。插入或粘贴的图片先暂存，保存时再整理。

如果文档有本地图片，Ctrl+S 会说明并提供：

- **原位置保存**：Markdown 保持原位置，图片复制到同级 `picture`，使用相对路径。
- **整理为文件夹**：复制当前文档和图片到同名文件夹，图片放进 `picture`，原文档和原图片都保留。之后按文件夹文档处理。
- **取消**：不写入，保留暂存内容。

没有本地图片时直接保存回原位置。源文件被其他程序修改时，覆盖前会再次确认。另存为使用同名文档文件夹的结构。

## 图片与 ZIP

点击工具栏 **图片** 选择本地图片，或在编辑/源码区域 Ctrl+V 粘贴剪贴板图片。支持 PNG、JPEG、GIF、WebP、BMP，单次插入上限 8 MB，已有引用的单张图片整理上限 20 MB，单次整理总量上限 200 MB。

程序只整理标准 Markdown 图片语法及图片引用定义，忽略代码块中的示例。支持相对路径、`file:` 本地地址、旧版 `data:image`；本地图片缺失时会报错，保留原文档和暂存。图片按内容哈希命名，避免重名覆盖，重复内容只保存一份。

点击 **打包 ZIP**，选择压缩包路径。ZIP 中包含同名顶层文件夹、**当前编辑内容**的 Markdown 和引用的本地图片目录 `picture`。无需先保存 Markdown；打包不修改原文件，也不清理临时目录。网络图片仅保留链接，离线时可能无法显示。未引用的附件和其他文档不会打包。

## 编辑功能

- 编辑 / 阅读 / 源码 / 分屏；文档大纲、自动草稿、专注模式。
- 表格浮动网格点击插入；边缘 + 增行增列；右键增删；列宽拖动。
- 数学公式模板、独立括号、希腊字母与常用字符；LaTeX 源码实时预览；独立公式居中；双击编辑。
- 工具栏 **自动编号** 统一处理正文与标题：光标在正文时使用有序列表连续编号；在标题时按全文标题层级编号。再次点击取消当前编号。单标题操作保留其他标题内容，并暂停全文自动重排；全文标题编号仍有独立入口。
- 多语言代码块与语法高亮，左上角切换语言，右上角折叠。
- 70%–180% 缩放、三种页宽，记忆显示设置。

## 开发与验证

建议使用 Node.js 22 LTS 或更新版本。

```powershell
npm install --registry=https://registry.npmjs.org
npm run desktop          # 构建并启动 Electron
npm run dev              # 浏览器开发版，完整文件及图片管理请使用桌面版
npm test                 # 编号、图片引用、保存取消/失败/清理、ZIP、跨根目录及覆盖冲突测试
npm run test:desktop     # 基础编辑功能交互测试
npm run test:improvements # 编号、语言、缩放交互测试
npm run test:v03         # 表格、符号、图片及文件树交互测试
npm run test:v04         # 三种文件流程、标签页、图片资源、ZIP、临时目录清理
npm run test:v041        # 正文/标题上下文编号与快捷键
npm run dist             # 生成 release/MDTeX 目录版
```

首次安装 Electron 如遇下载问题，可在当前 PowerShell 设置镜像后重试：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm install --registry=https://registry.npmjs.org
```

构建使用 Vite 生成界面、esbuild 打包 Electron 主进程和文件处理依赖。免安装程序暂未做代码签名。

## 当前边界

草稿和标签索引会保存在本机，不能替代文件备份。升级前的旧文档如果尚未获得当前版本的文件访问授权，请通过“打开”重新选择原文件；未保存编辑内容仍可保留为草稿。

所见即所得编辑会规范化 Markdown 的空行、列表和表格等排版。脚注、Mermaid、自定义 HTML 等非标准扩展不保证往返保真。图片整理暂不扫描原始 HTML 的 `<img>`，不处理 SVG，也不下载网络资源。

数学公式使用 KaTeX 支持的语法子集。浏览器开发版只提供基本编辑和 Markdown 下载；本机文件管理、暂存、图片整理与 ZIP 使用 Electron 桌面接口。当前不提供云同步。
