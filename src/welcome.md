# 让思考，自然发生

一份安静的文档，一点清晰的表达。欢迎来到 **MDTeX**，你的 Markdown 写作空间。

> 把注意力留给内容，把排版交给编辑器。

## 从这里开始

你可以直接在这张纸上写作。用 **加粗** 强调重点，用 *斜体* 记录灵感，或输入 `/` 唤起快捷插入菜单。

- **编辑**：所见即所得，像写文档一样自然
- **阅读**：专注于渲染后的内容，安心浏览
- **源码 / 分屏**：在 Markdown 与排版之间自由切换

## 公式，也可以很简单

在段落中放置光标，或选中多个段落，可使用工具栏的靠左、居中、靠右按钮排版。

点击工具栏的 **公式**，在弹窗顶部选择“行内公式”或“独立公式”，挑选一个模板，修改其中的变量。行内公式 $E = mc^2$ 会融入文字，独立公式默认居中，可通过工具栏的段落对齐按钮调整：

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

### 给复杂一点的想法

$$
\mathcal{L}(\theta) = \frac{1}{N} \sum_{i=1}^{N} \left(y_i - f_\theta(x_i)\right)^2
$$

选中正文中的 LaTeX 内容，点击工具栏 **公式** 可以直接转换；选中完整段落时，公式默认独立居中。

双击已有公式即可再次编辑。按 **Ctrl + Shift + M** 随时插入新公式。

## 表格，不必反复敲竖线

| 功能 | 操作方式 | 状态 |
| --- | --- | --- |
| 插入表格 | 工具栏选择行列 | 已就绪 |
| 增加行列 | 移到表格边缘，点击 + | 已就绪 |
| 删除行列 | 在单元格内点击右键 | 已就绪 |

右键表格可分别设置标题行、标题列，两者可以同时存在。

## 标出重点

选中文字，点击工具栏 **文字高亮**，选择淡红、黄、绿、橙、灰色；选择“无色”移除高亮。也可直接输入 `==重点==` 得到 ==黄色高亮==。

## 让结构保持有序

按 **Ctrl + Alt + N** 为所有标题自动编号。新增、移动或删除标题，编号都会按层级更新；按 **Ctrl + Alt + Shift + N** 移除编号。

### 留一段代码

```python
def hello(name):
    return f"你好，{name}。开始写作吧。"

print(hello("世界"))
```

代码块左上角可以选择 Python、JavaScript、C++、SQL、MATLAB 等语言，并显示语法高亮；点击右上角即可折叠。

只想编号某一个标题？把光标放入标题，在工具栏 **编号** 菜单选择“仅编号当前标题”，或按 **Ctrl + Alt + H**；加上 Shift 可以移除当前编号。仅统计参与编号的标题；新增或移除编号时，后续编号按顺序更新。

在右下角调整 **页面缩放与宽度**，或用 **Ctrl + 鼠标滚轮** 放大文字。显示设置会自动记住。正文采用手动保存：按 **Ctrl + S** 写入文件；没有保存路径时默认保存到 exe 同级的 `MDTeX-data/documents`。按 **Ctrl + Shift + S** 另存为到其他位置。关闭有修改的文档时，可选择保存、不保存或取消。

文档大纲会随页面滚动高亮当前章节。外部程序修改了文件后，没有未保存修改时会自动刷新；有修改时会提示处理冲突。
